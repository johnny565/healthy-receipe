Healthy Recipe Finder

Healthy Recipe Finder is a responsive recipe website designed to help users discover simple, wholesome meals made with everyday ingredients. The website features a clean layout, an earthy colour palette, and recipe cards that showcase quick meal ideas.

Features

- Responsive design: Adapts to desktop, tablet, and mobile screen sizes.
- Home section: Introduces the website and encourages visitors to explore recipes.
- About section: Explains the purpose and benefits of the recipe finder.
- Recipe collection: Displays breakfast, lunch, and dinner ideas.
- Recipe preparation times: Shows estimated preparation times for each featured meal.
- Navigation: Provides links to the Home, About, and Recipes sections.
- Accessible markup: Includes semantic HTML elements, descriptive image alt text, and navigation labels.
- Custom styling: Uses CSS variables, grid layouts, hover effects, and media queries.

Technologies Used

- HTML5
- CSS3
- Responsive web design

Getting Started

Prerequisites

You need a web browser and a code editor, such as Visual Studio Code.

Installation

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Ensure that `index.html`, `style.css`, and the `images` folder are in the correct locations.
4. Open `index.html` in your web browser.

Alternatively, use the Live Server extension in Visual Studio Code to preview the website locally.

Customization

- Edit `index.html` to change the website content and featured recipes.
- Edit `style.css` to customize colours, typography, spacing, and responsive layouts.
- Replace the images in the `images/` folder with your own food photography, keeping the filenames consistent or updating the image paths in the HTML.

Current Limitations

The current version is a static website built with HTML and CSS. Recipe search and ingredient filtering are described in the website content but are not yet implemented. The featured recipe cards also do not contain detailed recipe instructions.

Future Improvements 

- Add functional recipe search and ingredient filtering.
- Include detailed ingredients and cooking instructions.
- Add recipe categories and dietary filters.
- Improve keyboard navigation and accessibility.
- Add more recipes and food photography.
